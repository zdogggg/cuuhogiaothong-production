# Cứu Hộ Giao Thông 123 🚒

Website Landing Page chuyên nghiệp dành cho dịch vụ cứu hộ giao thông. Được thiết kế tối ưu hóa cho trải nghiệm người dùng (UI/UX) và hiển thị xuất sắc trên mọi thiết bị (Responsive).

## Tính năng nổi bật
- **Giao diện hiện đại, chuẩn SEO**: Tông màu vàng - đỏ nổi bật, mang lại cảm giác an tâm và chuyên nghiệp.
- **Tương thích mọi thiết bị (Responsive)**: Hiển thị hoàn hảo trên Mobile, Tablet và Desktop.
- **Tích hợp Bản đồ vệ tinh**: Google Maps nhúng sẵn chế độ vệ tinh (Satellite) giúp khách hàng dễ dàng xem đường đi thực tế.
- **Quy trình cứu hộ trực quan**: Thiết kế dạng Grid rõ ràng, bắt mắt.
- **Hệ thống liên hệ nhanh**: Tích hợp các nút gọi Hotline và Zalo nổi (Floating buttons) luôn bám sát màn hình để khách hàng liên hệ nhanh nhất.
- **Hỗ trợ Docker**: Cấu hình sẵn `Dockerfile` và `docker-compose.yml` (sử dụng web server Nginx) để dễ dàng triển khai lên máy chủ.

## Công nghệ sử dụng
- HTML5
- CSS3 (Custom Variables, CSS Grid, Flexbox)
- Vanilla JavaScript
- FontAwesome 6 (Icons)
- Google Fonts (Inter)

## Hướng dẫn sử dụng & Triển khai

### 1. Chạy thuần túy (Môi trường máy tính)
Chỉ cần nhấp đúp vào file `index.html` để mở bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari...) là trang web sẽ hiển thị ngay lập tức.

### 2. Triển khai lên Server bằng Docker
Dự án đã được tích hợp sẵn cấu hình Docker. Bạn có thể dễ dàng build và chạy web server bằng các lệnh sau:

```bash
# Build và chạy container trong background
docker-compose up -d
```
Sau đó truy cập trang web thông qua cổng mặc định được cấu hình (thường là port 80).
